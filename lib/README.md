## Components

1. ### nvim

    Neovim config (lua-based) which includes _LazyNvim_, _Mason_, _LSP-Config_, _Mini-Nvim_, _Snacks_, and more. Provides an organized directory structure, along with several utilites for configuring additional LSP servers and tools. Optional extras can be found in [extras/nvim](https://github.com/worldshredder/dotfiles/tree/main/extras).

    - [Documentation](https://github.com/worldshredder/dotfiles/blob/main/lib/nvim/README.md)
    - [Key Bindings](https://github.com/worldshredder/dotfiles/blob/main/lib/nvim/docs/bindings.md)

2. ### tmux

    A simple Tmux config with a _Tmux2k_ statusline and _Sesh_ for session management.
    
    - [Documentation](https://github.com/worldshredder/dotfiles/blob/main/lib/nvim/README.md)
    - [Key Bindings](https://github.com/worldshredder/dotfiles/blob/main/lib/nvim/docs/bindings.md)
